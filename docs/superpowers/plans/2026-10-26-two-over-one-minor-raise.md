# 2/1 minor raise after a direct game-forcing response

## Scope

After an uncontested, unpassed 1M–2m direct 2/1 response, an unbalanced opener with 12+ HCP and four-card support raises to 3m when no higher-priority major description applies. Balanced 18–19 HCP hands retain their existing 2NT rebid. Responder with four-card support completes game at 5m. The 2♣ response may still receive a natural 2♦ rebid when opener lacks four-card club support.

## Verification

- Test the 1♠–2♣–3♣–5♣ sequence.
- Test the 1♠–2♦–3♦–5♦ sequence.
- Test an unbalanced 18–19 HCP opener with a four-card minor fit.
- Preserve existing balanced 18–19 HCP 2NT rebid coverage.
- Run `pnpm test`, `pnpm typecheck`, `pnpm lint`, and `git diff --check`.
