# Opener reverse after a one-level response

## Scope

When opener holds a four-card higher-ranking side suit that cannot be shown at the one level because responder's one-level suit is higher, opener shows it at the two level with 16+ HCP. For example, 1♦–1♠–2♥. Hands below 16 HCP do not make this reverse.

## Verification

- Cover both configured bidding styles at 16+ HCP and below the reverse range.
- Run `pnpm test`, `pnpm typecheck`, `pnpm lint`, and `git diff --check`.
